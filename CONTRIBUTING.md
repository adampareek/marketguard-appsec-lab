# Contributing

Keep contributions focused on secure coding and reproducible local demonstrations.

For a new vulnerability module, include:

1. A vulnerable behavior with a clear root cause.
2. A hardened implementation.
3. A regression test comparing the two modes.
4. A short risk/remediation note.
5. A local-only demonstration if an exploit script is necessary.

Never add real credentials, course flags, proprietary source code, or exploit code aimed at external systems.
